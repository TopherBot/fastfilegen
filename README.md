# fastfilegen

**FastFileGen** – a minimalist Python CLI that instantly spawns a batch of files with auto‑renamed, collision‑free names.

---

## 📖 Overview

- **Goal** – Generate N files (empty or with a one‑line template) in a target folder with virtually no latency.
- **Features**
  - Auto‑incremented naming (`prefix_001.ext`, `prefix_002.ext`, …).
  - Automatic collision handling – if a file already exists, the tool bumps the counter until a free name is found.
  - Customizable prefix, suffix, extension, and optional inline content.
  - Cross‑platform (Python 3.8+). No external dependencies.
  - Single‑file implementation – clone, chmod, and you’re ready.

---

## 🚀 Installation

```bash
# Clone the repo (or just copy fastfilegen.py)
git clone https://github.com/your‑username/fastfilegen.git
cd fastfilegen
# Make it executable (optional)
chmod +x fastfilegen.py
# Run directly with python
python3 fastfilegen.py --help
```

Or install globally via `pip` (the script is also packaged as a console script):

```bash
pip install git+https://github.com/your‑username/fastfilegen.git
```

---

## 📦 Usage

```bash
# Create 10 empty .txt files with default naming
python3 fastfilegen.py -n 10

# Custom prefix/suffix and extension
python3 fastfilegen.py -n 5 -p "demo" -e ".log"

# Provide a one‑line template for each file
python3 fastfilegen.py -n 3 -c "Generated by FastFileGen on $(date)"

# Target a specific directory (created if missing)
python3 fastfilegen.py -n 20 -d ./tmp/files
```

### Options summary

| Flag | Description |
|------|-------------|
| `-n`, `--number` | Number of files to generate (required). |
| `-p`, `--prefix` | Filename prefix (default: `file`). |
| `-s`, `--suffix` | Filename suffix (default: empty). |
| `-e`, `--ext`    | File extension including the dot (default: `.txt`). |
| `-c`, `--content`| One‑line text written to each file (default: empty). |
| `-d`, `--dir`    | Destination directory (default: current working directory). |
| `-h`, `--help`   | Show help message. |
